# Code of Conduct

Pigoune follows the [GNOME Code of Conduct](https://conduct.gnome.org/).

In short: be friendly and patient, be welcoming, be considerate, be respectful and be careful
in the words you choose. Everyone taking part in this project, in issues, pull requests or any
other space, is expected to follow it.

To report a problem, contact the maintainer through their GitHub profile.
