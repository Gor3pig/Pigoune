# Pigoune

> [Français](README.md) · English

**P**lateforme d’**I**cônes et **G**raphismes **O**rganisée, **U**nifiée, **N**ative et **É**légante.

Pigoune is a native GNOME application for building and managing a personal library of graphical assets.

Its goal is to provide a fast, visual and reliable home for icons, logos, illustrations and other graphical resources without relying on a traditional filesystem hierarchy.

## Project status

Pigoune is currently in early development.

The first stable release will focus on a robust local asset library, a polished GNOME interface, reliable storage and imports, collections, tags, search, previews, export, backup and recovery.

## Principles

- Native Linux/GNOME application
- Local and offline by design
- No account, cloud service, telemetry or analytics
- Imported assets become independent from their original location
- Original binary content is preserved
- Portable and self-contained libraries
- Reliability and recoverability before premature optimization

## Planned technologies

- Rust
- GTK 4
- Libadwaita
- SQLite
- Glycin
- Flatpak
