# Pigoune

> Français · [English](README.en.md)

**P**lateforme d’**I**cônes et **G**raphismes **O**rganisée, **U**nifiée, **N**ative et **É**légante.

Pigoune est une application native GNOME destinée à créer et gérer une bibliothèque personnelle d’assets graphiques.

Son objectif est d’offrir un espace rapide, visuel et fiable pour conserver des icônes, logos, illustrations et autres ressources graphiques, sans dépendre d’une arborescence traditionnelle de fichiers.

## État du projet

Pigoune est actuellement en phase initiale de développement.

La première version stable se concentrera sur une bibliothèque locale robuste, une interface GNOME soignée, un stockage et des imports fiables, les collections, les tags, la recherche, les aperçus, l’export, les sauvegardes et la récupération.

## Principes

- Application native Linux/GNOME
- Fonctionnement local et hors ligne
- Aucun compte, service cloud, télémétrie ou analytics
- Les assets importés deviennent indépendants de leur emplacement d’origine
- Le contenu binaire original est préservé
- Bibliothèques autonomes et portables
- Fiabilité et récupération avant optimisation prématurée

## Technologies prévues

- Rust
- GTK 4
- Libadwaita
- SQLite
- Glycin
- Flatpak
