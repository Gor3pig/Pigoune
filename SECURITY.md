# Security policy

## Reporting a vulnerability

Please do not report security issues in public issues.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/Gor3pig/Pigoune/security/advisories/new). Describe the problem, the affected version and, if possible, how to reproduce it. You will get an answer as soon as possible, and the fix will be credited to you unless you prefer otherwise.

## Supported versions

Security fixes are released for the latest version of Pigoune only. Please make sure the problem still happens with the [latest release](https://github.com/Gor3pig/Pigoune/releases/latest) before reporting it.

## Scope

Pigoune works fully offline and only reads the files you import or open. Reports about how it handles untrusted files (crafted images, damaged libraries) are especially welcome.
