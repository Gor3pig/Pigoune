Pigoune

All your graphic assets, organized and within reach.

Install View on GitHub

Free software for Linux, in English and French.

What is Pigoune?

Icons in Downloads, logos in an old project folder, an SVG lost somewhere on the desktop… Pigoune gathers all of them in a single library, neatly organized and pleasant to browse.

Drop your graphic assets in: Pigoune keeps a safe copy (your original files are never touched), helps you organize them and hands them back with a simple drag and drop whenever you need them.

Why “Pigoune”?

Its name is an acronym that sums up what it is.

Platform for Icons and Graphics Organized, Unified, Native and Elegant

Features

Drop

Drag files or whole folders: SVG, PNG, JPEG, WebP, AVIF, JPEG XL, GIF, TIFF, BMP and ICO. Every image is checked before it comes in, and duplicates are recognized automatically.

Organize

Nested collections, tags and favorites, plus a note, a source, a license and an author for each asset.

Find

Instant search and filters by type or favorite, even among thousands of assets. Clicking a collection or a tag shows you where an asset lives.

Reuse

Drag an asset into any application, open it with another one, copy it to the clipboard or export it to a folder, as it is or converted to PNG, JPEG, WebP, AVIF or ICO.

Enjoy

A thumbnail grid with adjustable size, animations (GIF, PNG, WebP) on hover, and a detailed preview with zoom at the press of Space.

Relax

The trash and undo with Ctrl+Z: a mistake can always be fixed.

A closer look

Principles

  • Your originals are never modified: Pigoune works on its own copies.
  • Fully local: no account, no cloud, no telemetry.
  • Portable libraries: a plain folder you can keep anywhere and take to another computer.
  • Made for GNOME: a native, polished app in light and dark mode, usable with the keyboard and a screen reader, and adaptive to small windows.

Which systems?

Pigoune runs on Linux, packaged as a Flatpak.

Supported

Linux, any distribution

Any distribution that supports Flatpak, whatever the desktop: GNOME, KDE Plasma, Xfce, Cinnamon and others.

  • Fedora
  • Ubuntu
  • Debian
  • Linux Mint
  • Pop!_OS
  • openSUSE
  • Arch Linux
  • elementary OS
  • Zorin OS

Required

A 64-bit PC

With an Intel or AMD processor (x86_64), like most desktop and laptop computers. ARM devices, such as the Raspberry Pi or Apple Silicon Macs running Linux, are not supported.

Not available

Windows and macOS

Pigoune is made for Linux and the GNOME platform. There is no version for Windows or macOS.

Install

1. Set up Flatpak

Pigoune is distributed as a Flatpak. Fedora, Linux Mint, Pop!_OS and many other distributions ship Flatpak already. On Ubuntu and a few others, set it up first by following the official guide for your distribution, then restart your session.

2. Install Pigoune

Click the button below and open the file with Software: it installs Pigoune, along with the GNOME runtime it needs from Flathub.

Install Pigoune

Or run this command:

flatpak install --user https://gor3pig.github.io/Pigoune/pigoune.flatpakref

3. Stay up to date

Pigoune updates itself like your other apps: Software offers each new version, and flatpak update installs it too. Every update is signed, so only official versions are accepted.

Installed from a downloaded .flatpak file?

If you installed Pigoune 1.5 or older from a downloaded .flatpak file, it does not update itself. Switch once to automatic updates with these two commands. Your libraries and settings are kept.

flatpak uninstall --user io.github.gor3pig.Pigoune
flatpak install --user https://gor3pig.github.io/Pigoune/pigoune.flatpakref

The .flatpak file of each version is still attached to its release, for those who prefer it.
