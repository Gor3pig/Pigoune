What is Pigoune?

Icons in Downloads, logos in an old project folder, an SVG lost somewhere on the desktop… Pigoune gathers all of them in a single library, neatly organized and pleasant to browse.

Your original files are never touched: Pigoune keeps a safe copy and hands it back with a simple drag and drop.

Platform for Icons and Graphics Organized, Unified, Native and Elegant

What Pigoune does

Drop

Drag files or whole folders: SVG, PNG, JPEG, WebP, AVIF and many more. Duplicates are recognized automatically.

Organize

Nested collections, smart collections that fill themselves, tags inside tags, favorites, and a note and a license for each asset.

Find

Instant search and filters by type, orientation or color, even among thousands of assets.

Reuse

Drag an asset into any application, copy it or export it, converted if you want.

Annotate

Draw on a screenshot or any image: arrows, text, blur. The original is never modified.

Enjoy

A thumbnail grid, a detailed preview with zoom, and a trash with Ctrl+Z so a mistake can always be fixed.

From your library to your desktop

Install

1. Set up Flatpak

Fedora, Linux Mint, Pop!_OS and many other distributions ship Flatpak already. On Ubuntu and a few others, follow the official guide for your distribution first, then restart your session.

2. Install Pigoune

Click the button below and open the file with Software, or run this command:

Install Pigoune

flatpak install --user https://gor3pig.github.io/Pigoune/pigoune.flatpakref

3. Stay up to date

Pigoune updates itself like your other apps: Software offers each new version, and every update is signed.

Pigoune runs on any Linux distribution that supports Flatpak (GNOME, KDE Plasma, Xfce and others), on a 64-bit Intel or AMD PC. There is no version for Windows, macOS or ARM devices.
